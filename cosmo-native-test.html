Cosmo's Cosmic Adventure — Native Test

This is a diagnostic test for the graphics problem we found in the browser DOS version.

Why are we testing this?

The browser version is producing the same graphical corruption with two very different DOSBox configurations. The modern Cosmo source port uses its own EGA emulation instead of DOSBox, so it gives us a clean comparison.

The native port is an independent project built from the original game's code. Its EGA implementation specifically emulates the hardware features Cosmo uses, including EGA write modes and latches.

Download Native Cosmo

What to do

  1. Click Download Native Cosmo.
  2. Download the Windows ZIP.
  3. Extract it somewhere on your computer.
  4. Run the Cosmo program inside it.
  5. Play long enough to reach the first actual game area, not just the title screen.

If the native version looks correct: that strongly points to the browser DOSBox layer as the source of our graphics problem.

If the native version has the same corruption: then we need to investigate the game data or an original Cosmo rendering problem instead.
